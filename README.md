# Algorithms & Problem-Solving – Level 1 (Clean Code Solutions)

> From Spaghetti Code to Clean, Controlled, and Scalable Solutions.

## 📘 About This Repository

This repository contains my solutions to the 50 problems from **Algorithms & Problem-Solving – Level 1**, revisited using a more structured and professional approach.

The goal is not just to solve problems, but to learn **how to think through problems and write better code**.

## 🎯 What I Will Learn

- **Problem-Solving:** Strengthen logical thinking and break problems into smaller tasks.
- **Divide and Conquer:** Solve complex problems by dividing them into manageable sub-problems.
- **Functions:** Build modular, focused, and reusable solutions.
- **Clean Code:** Write readable, organized, and maintainable C++ code.
- **Code Quality:** Reduce repetition, simplify debugging, and make future improvements easier.
